# 云启科技 AI IT 服务助手 Demo

## 项目介绍

本项目是一个企业内部 AI IT 服务助手的前端演示 Demo，展示员工自助服务、IT 人工协同，以及处理经验沉淀的完整业务流程。

### Demo 包含哪些端

| 工作台 | 使用角色 | 展示内容 |
| --- | --- | --- |
| 员工服务端 | 员工 | 飞书式机器人聊天窗口，用于提问、故障诊断、填写申请卡片、与 IT 沟通及确认结单 |
| IT 工作端 | IT 服务人员 | 查看工单、接单、审批、进入原会话、查看内部摘要、人工回复及提交结单申请 |
| 知识库 | IT 提交人员、审核人员 | 知识卡片列表、搜索分类、详情编辑、新建与批量导入、知识审核发布 |

通过顶部导航切换工作台，各端共享会话与工单数据，方便一人演示不同角色。

### 可以体验的四条链路

1. **知识问答**：员工提问 → 机器人回答 → 结束，不产生工单。
2. **故障自助解决**：员工描述故障 → 故障分类引导 → 展示对应方案 → 员工解决问题。
3. **人工协同与知识沉淀**：自助方案未解决 → 员工提单 → IT 接单并进入原会话 → 查看摘要、人工指导 → IT 申请结单 → 员工确认 → IT 提交长尾解决方案 → AI 总结 → 人工审查 → 定期审核发布。
4. **设备申请**：员工提出申请 → 填写申请卡片 → IT 接单、审批 → 设备送达并提交结单申请 → 员工确认。

## 运行方式

直接在浏览器打开在线 Demo，无需安装依赖或配置模型 API：

[打开云启科技 AI IT 服务助手 Demo](https://zii-i-del.github.io/yunqi-ai-it-demo/)

可将此链接发送给其他人体验。会话、工单和知识候选仅保存在各自浏览器中，不会跨设备同步。

## 技术栈

- HTML、CSS、原生 JavaScript。
- localStorage 保存会话、工单和知识候选数据。
- 前端规则与预置内容模拟意图识别、AI 回答和摘要生成。

## 核心功能与演示流程

演示前可点击顶部“重置演示”，从空白状态开始。以下每条链路均从员工端新建会话发起。

### 8.1.1 知识问答

**展示目标：明确的咨询直接回答，不创建工单。**

| 步骤 | 角色与所在端 | 操作及结果 |
| --- | --- | --- |
| 1 | 员工 · 员工服务端 | 点击“＋ 新建会话”，输入“Mac 如何配置公司 VPN？” |
| 2 | 机器人 · 员工服务端 | 展示步骤化回答和知识来源 |
| 3 | 员工 · 员工服务端 | 展开“查看知识来源”，了解回答依据；本次问答结束 |

### 8.1.2 故障自助解决

**展示目标：通过故障分类确认具体问题，再提供完整处理方案。**

| 步骤 | 角色与所在端 | 操作及结果 |
| --- | --- | --- |
| 1 | 员工 · 员工服务端 | 新建会话，输入“VPN 连不上” |
| 2 | 机器人 · 员工服务端 | 展示故障类型缩小范围 |
| 3 | 员工 · 员工服务端 | 选择选项或输入文字，确认具体故障类型，例如“连接超时 → 每次连接都超时” |
| 4 | 机器人 · 员工服务端 | 展示对应的完整处理方案 |

两级分类用于区分明确的故障类型，不将每个检查操作拆成一轮问答。方案下方不展示“已恢复 / 仍有问题 / 提单”按钮。

### 8.1.3 故障提单、人工处理与知识沉淀

**展示目标：自助无法解决时，保留上下文交给 IT；处理结束后，将有价值的长尾方案提交审核。**

#### 3.1 员工提交工单

| 步骤 | 角色与所在端 | 操作及结果 |
| --- | --- | --- |
| 1 | 员工 · 员工服务端 | 新建会话，输入“我的显示器有问题”，选择“帮我排查”，完成两级分类并查看方案 |
| 2 | 员工 · 员工服务端 | 点击输入框旁的常驻“提单”入口 |
| 3 | 机器人 · 员工服务端 | 展示提单卡片，汇总故障类型、已知环境及处理反馈 |
| 4 | 员工 · 员工服务端 | 确认问题描述，补充设备环境，可选填写提单原因，点击“确认提交工单” |

提交后生成“AI 升级”工单，返回工单编号。

**补充体验：意图不明确时的澄清**

员工在新会话中输入“我的显示器有问题”时，“故障诊断”和“设备报修”两个候选意图的置信度接近，系统无法直接确定员工希望排查还是报修，因此先展示“帮我排查 / 直接报修”供员工确认。

选择“帮我排查”后进入故障分类；选择“直接报修”后展示报修卡片。这里的置信度为预置演示结果，不在员工聊天窗口展示分数或内部判断说明。

#### 3.2 IT 接单并进入原会话

演示者通过顶部导航切换至 IT 工作端。

| 步骤 | 角色与所在端 | 操作及结果 |
| --- | --- | --- |
| 5 | IT · IT 工作端 | 在工单列表找到新工单，点击打开独立详情弹窗 |
| 6 | IT · IT 工作端 | 查看问题信息，点击“接单”，再点击“进入原会话” |
| 7 | IT · IT 工作端 | 查看顶部“交接摘要 · 仅 IT 可见”，了解故障、环境和已有处理记录 |
| 8 | IT · IT 工作端 | 阅读历史聊天，在回复框输入进一步处理建议并发送 |
| 9 | 员工 · 员工服务端 | 切回原会话，查看 IT 回复并补充处理结果 |

内部摘要与聊天记录分区展示，不发送到员工端。人工处理期间，机器人暂停自动业务答复，员工无需重新描述问题。

#### 3.3 IT 申请结单，员工确认

| 步骤 | 角色与所在端 | 操作及结果 |
| --- | --- | --- |
| 10 | IT · IT 工作端 | 在会话弹窗点击“填写结论并申请结单”，返回工单详情 |
| 11 | IT · IT 工作端 | 填写处理结论，点击“提交结单申请” |
| 12 | 员工 · 员工服务端 | 在原会话收到结单确认卡片 |
| 13 | 员工 · 员工服务端 | 点击“已解决，确认结单”，工单关闭 |

员工也可选择“未解决，继续处理”，工单返回处理中，由 IT 继续处理。

#### 3.4 长尾解决方案沉淀

| 步骤 | 角色与所在端 | 操作及结果 |
| --- | --- | --- |
| 14 | IT · IT 工作端 | 打开已关闭的 AI 升级工单，点击“提交长尾故障解决方案” |
| 15 | 系统 · 知识库 → 知识审核 | 使用 AI 总结模板生成候选知识，关联原工单 |
| 16 | IT / 审核人员 · 知识库 → 知识审核 | 检查并修改适用范围、原因和解决方法，填写脱敏与验证备注 |
| 17 | 审核人员 · 知识库 → 知识审核 | 点击“人工审查通过，纳入定期审核” |
| 18 | 审核人员 · 知识库 → 知识审核 | 点击“执行本期审核并发布”，完成知识沉淀 |

人工回复不会自动入库。Demo 通过按钮模拟定期审核，不运行真实定时任务或更新真实知识库。

### 8.1.4 设备申请与交付确认

**展示目标：明确申请直接展示卡片，经 IT 审批、交付后由员工确认结单。**

| 步骤 | 角色与所在端 | 操作及结果 |
| --- | --- | --- |
| 1 | 员工 · 员工服务端 | 新建会话，输入“帮我申请一台显示器” |
| 2 | 机器人 · 员工服务端 | 直接展示设备申请卡片，不进入故障排查 |
| 3 | 员工 · 员工服务端 | 填写设备类型、数量、用途和送达地点，点击“提交申请” |
| 4 | IT · IT 工作端 | 点击新工单打开详情弹窗，查看申请材料并接单 |
| 5 | IT · IT 工作端 | 点击“审批通过” |
| 6 | IT · IT 工作端 | 模拟设备送达，点击“设备已送达，提交结单申请” |
| 7 | 员工 · 员工服务端 | 在原会话收到设备交付确认卡片 |
| 8 | 员工 · 员工服务端 | 点击“已收到，确认结单”，工单关闭 |

员工选择“未收到 / 有问题”时，工单返回处理中。

设备申请属于“正常申请”，与自助故障未解决产生的“AI 升级”工单分别标记。

## 工单状态

```text
待处理 → 处理中 → 待员工确认 → 已关闭
                  ↓ 未解决
                处理中
```

IT 提交结单申请后，必须由员工确认才能关闭工单。

## 数据与重置

演示数据保存在当前浏览器中，刷新页面后仍可恢复。

点击顶部“重置演示”，确认后可清空本 Demo 的会话、工单和知识候选，从头演示。请使用虚构信息测试。

## 实现范围

本项目为纯前端交互演示：

- 未接入真实飞书、iTop、审批系统或知识库。
- 未调用真实大模型，回答、分类和摘要使用预置内容及模板。
- 审批、设备送达和知识发布均为模拟操作。
- 工作台切换用于演示不同角色，不代表真实身份认证与权限控制。

## 知识库使用

知识库主页展示知识卡片与总数、已发布、待审核、已停用统计，支持关键词搜索、分类与状态筛选。点击卡片查看正文、来源、适用范围、维护人、版本和时间；可编辑或停用。

右上角“知识审核”进入审核工作台；“新建知识”创建候选；“批量导入”支持 JSON 文件或粘贴 JSON 数组，并提供示例与模板。单次最多 50 条、文件最多 1 MB，标题去重且全批次校验通过才导入。所有新建、导入和编辑的知识均需人工审查、定期审核后发布。已发布卡片编辑后进入重新审核。

知识库为前端管理演示，含 6 条示例知识，未建设检索索引或接入真实知识库；发布状态不会改变预置机器人的回答逻辑。

## 工单查询与服务会话

- 员工端左侧提供“最近会话 / 我的工单”两个 Tab，可查看当前浏览器的全部演示工单。提交后，原聊天窗口展示工单卡；点击后切换至“我的工单”，右侧展示工单信息、提交字段与接单、审批、交付、结单确认进度；点击“返回关联会话”恢复聊天，不弹窗。
- 诊断方案及知识问答下方提供可展开的演示来源引用。
- 输入“人工”“转人工”或“人工客服”，与点击常驻“提单”一样，先填写提单卡片；已有工单时不会重复创建。
- IT 工作端提供“工单工作台 / 服务会话”两个入口。接单后，IT 可直接在服务会话列表切换对话，也可从工单点击“进入原会话”。IT 消息在右侧，员工与机器人历史消息在左侧；顶部交接摘要仅 IT 可见，可折叠。
- 会话中点击“工单详情”可办理审批、提交结单申请或沉淀解决方案。员工继续在原聊天窗口确认结单。
